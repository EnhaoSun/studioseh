# Panda Restaurant — digital menu demo

Mobile-first interactive restaurant menu based on the original 22-page PDF.

The demo presents a sample of 19 dishes extracted from the PDF. Prices, quantities and translations require restaurant verification before production use. This is a browsing-only demo, not an ordering or payment system.

## GitHub Pages

Set **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
